## Selected projects

| Project | Research and results |

| **[SPY Prediction and Trading](https://github.com/martinezgtupacamaru/ETFs-prediction-trading)** | Predicting five-session SPY returns with eight XGBoost features from SPY, QQQ and TLT. Expanding-window validation, next-opening execution and transaction costs. The historical SPY/cash backtest returned **17.68% annualized net versus 12.10% for buy-and-hold** during 2022–2025. |
